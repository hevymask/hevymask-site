# hevymask-site
My portfolio site

## How to use?
1. Clone this repository.
2. Run `pnpm install` to install the dependencies.
4. Run `pnpm dev` to start develop!

## Technology
- React
- Vite
- TypeScript
- Cloudflare(wrangler)
- Tailwind CSS
- shadcn/ui(Radix UI)
- Tanstack Router
- Paraglide js
- Zod
- usehooks-ts
